# Assumptions

Shapes I've guessed at.

The rest of the repository is an idea and an argument. This folder is the part where I stopped
arguing and drew something, because at some point you have to be concrete or you're not saying
anything.

Everything in here is a guess. Not a draft standard, not an early specification, not something to
implement against. If any of it turns out to be right it will be after enough people have taken
it apart that it looks different.

Why it's in its own folder: I'd rather be able to throw all of this away without the idea going
with it. If the shapes are wrong but the question underneath is still interesting, that's a
perfectly good outcome. If the question only holds up while the shapes are in the room, then it
doesn't hold up.

## What's here

- [how-this-would-be-announced.md](how-this-would-be-announced.md) — the `robots.txt` line and
  where the files sit. The part that needs nothing new to exist.
- [what-an-organization-might-publish.md](what-an-organization-might-publish.md) — the
  organization-level description. Who it is, what it can do, how to reach it.
- [what-a-capability-might-look-like.md](what-a-capability-might-look-like.md) — one thing an
  organization can do, described in enough detail to actually act on.
- [when-being-wrong-is-expensive.md](when-being-wrong-is-expensive.md) — what happens to all of
  this when a mistake costs money. The most unresolved thing here, and the one I'd most like
  argued with.
- [how-an-agent-decides-to-reach-out.md](how-an-agent-decides-to-reach-out.md) — how an agent works
  out a task isn't its own to do, and what keeps it from calling out everywhere once it can. The
  caller's side of the boundary, kept private and per-company on purpose.
- [generate-your-own.md](generate-your-own.md) — a prompt you can paste into any AI to produce
  one of these for your own organization. Takes a minute.

## The useful thing to do with this

Run the prompt against a company you know well, then tell me where the output was wrong, thin, or
asking the wrong questions.

That's worth considerably more to me than an opinion about whether the shape is right. I've been
looking at these fields for a while and I've stopped being able to see what's missing from them.
Someone running it against a hospital, a freight company, or a municipal office will find the
holes in about five minutes.
